Cómo está hecho por dentro

El texto entra por arriba y sale como una probabilidad para cada token del vocabulario.

Dónde están los parámetros

Son los números que el entrenamiento ajustó. La salida reutiliza la matriz de embeddings (weight tying), por eso no suma.

Generar texto

El modelo escribe un token cada vez: calcula la probabilidad de todos los tokens del vocabulario, sortea uno y repite. Pasa el mouse sobre cualquier palabra para ver qué otras opciones consideró.

Vacío: el modelo empieza un texto desde cero.
0 elige siempre lo más probable; valores altos arriesgan más.
Más controles
Solo sortea entre los k tokens más probables (0 = sin límite).
Solo sortea entre los más probables que juntos suman p (1 = sin límite).
Más de 1 desalienta repetir palabras ya escritas.
Con la misma semilla se obtiene el mismo texto.

Chat de cuentos

Este modelo pasó por una segunda etapa, el ajuste fino supervisado (SFT), con miles de peticiones y su cuento. Por eso responde lo que pides en lugar de continuar tu frase: es el paso que convirtió a GPT en ChatGPT.

Atención: a qué palabras mira el modelo

Cada token genera un query (qué busca) que se compara con el key (qué ofrece) de los tokens anteriores. Haz clic en una palabra para ver hacia dónde mira. Nunca puede mirar hacia adelante: es la máscara causal.

Mapa completo

Filas: el token que procesa. Columnas: a cuál mira. El triángulo vacío es la máscara causal.

Cada cabeza mira cosas distintas

Elige una cabeza para verla en grande y en las palabras de arriba.

El espacio de significados

Cada token es un vector de números (su embedding). Nadie le dijo al modelo qué palabras se parecen: lo aprendió porque aparecen en contextos similares.

Palabras vecinas

Mapa de palabras

Cada línea es un grupo. Los 256 números de cada embedding se proyectan a 2 dimensiones (PCA).

Tokenizador BPE

Antes de entrar al modelo, el texto se corta en tokens. El tokenizador se entrenó con los cuentos: las palabras frecuentes quedan en un solo token y las raras se arman con pedazos.
